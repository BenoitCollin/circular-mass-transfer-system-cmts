## 🇬🇧 English Presentation
Welcome to the official repository for the **Circular Mass Transfer System (CMTS)**. This project delivers a complete open-source mechanical architecture engineered in Montreal, Canada. 

The CMTS utilizes a specific 2-axis layout with 4 rotating masses governed by an excentrated link/relay system named **DM ("Diriger Masse" / Directing Mass)**. Instead of a standard concentric rotation, the architecture constrains the masses to travel strictly within a perfect eccentric path (4.2 cm diameter). This maximizes the leverage advantage at 3 o'clock while mitigating the drag and mechanical binding typically encountered at the 6 and 12 o'clock dead centers.
